# Copilot Instructions — Omni-Workspace Root

> **CRITICAL: READ [docs/UNIVERSAL_LLM_INSTRUCTIONS.md](docs/UNIVERSAL_LLM_INSTRUCTIONS.md) FIRST.**

## 1. General Guidelines
- Adhere to the established workspace conventions and styles.
- Prioritize shared pointers and thread-safe methods in C++ (`_S` suffix).
- Use LibGDX patterns in Java projects.
- Use TypeScript best practices in web projects.

## 2. Naming Conventions
- C++: `sp<Type> ptr = ms<Type>();` for `shared_ptr`.
- Java: Follow standard Java/LibGDX conventions.
- Sync: Ensure versioning is updated in `VERSION` and `CHANGELOG.md`.
